## [→ 25_textures_and_assets] 25.14 Fonts and atlases

- **Live fonts** [C] `code/app.cpp:App::SetLanguage`: `g_gameFont = "speccy"`, `g_editorFont = "editor"`, `g_titleFont = "square"`; each is a set of atlases `data/textures/unicode/<font>.<lo>.<hi>.bmp` discovered with `Resource::ListResources("textures/unicode/", "<font>.*.*.bmp")` and loaded with default flags (mip + magenta key) — glyph metrics and UV formulae in P12 §24.7.
- **Atlas inventory** (138 files): Latin-1 `0020–00ff` 512×448 8-bit (3), Cyrillic `0410–042f`, `0430–044f` 512×64 24-bit (6), currency `20a0–20af` 512×32 24-bit (3), kana/CJK punctuation `square.3000.30ff` 512×512 8-bit (1), CJK ideographs `square.4e00.4eff` … `square.9e00.9eff` 256×256 24-bit (81), Hangul `square.ac00.acff` … `square.d700.d7ff` 512×512 4-bit (44, including the mis-named `square.bb00.bfff.bmp`, P12 §24.7).
- **What actually ships** (§25.3): the all-language retail `language.dat` contains Latin-1 for all three fonts, Cyrillic **only for speccy**, all CJK/Hangul for square; the Russian-only build adds Cyrillic for editor and square. The three currency atlases (`*.20a0.20af.bmp`, which cover € and other currency signs) are in **no** list, so a packed build cannot draw U+20A0–U+20AF; in an English-only build (`tools/englishlanguage.list`) only the three Latin-1 atlases exist. Missing atlases simply leave glyphs unmapped (`TextRenderer::GetTextureID` finds no range) [I].
- **Legacy single-bitmap fonts** `data/textures/editor_font*.bmp` (6) and `data/textures/speccy_font_*.bmp` (4): no code requests them (only a commented `GetTexture("textures/editor_font_normal.bmp")` in `code/app.cpp:App::Initialise`), and `tools/multiwinia_exclusions.txt` drops them from packing [C]. `TextRenderer::BuildOpenGlState` (the legacy path) would only be used for a font name ending in `.bmp`, which no caller passes.
- **For a new engine**: replace with a runtime glyph cache over a licensed vector font (one regular + one display face), fixed advance not required; keep the two-pass outline/additive text look (P12 §24.7).

## [→ 25_textures_and_assets] 25.15 Shapes: conventions the catalogue relies on
