### Display-mode enumeration [C] `ListAllDisplayModes` (identical in Win32 and DirectX variants)

Loop `EnumDisplaySettings(NULL, i, &devMode)` for i = 0,1,… until it fails; keep modes with `dmBitsPerPel ≥ 15 && dmPelsWidth ≥ 640 && dmPelsHeight ≥ 480`; de-duplicate by (width, height) regardless of bit depth; per resolution collect unique `dmDisplayFrequency` values. Order is driver enumeration order (not sorted). `devMode.dmSize` is not initialised before the call [C] (works in practice; strictly required by Win32). The list feeds the options screen (`code/interface/prefs_screen_window.cpp`, P17b) and `GetClosestResolution`. Colour depths are **not** stored per resolution; depth is a separate preference.

### WindowManagerWin32 — OpenGL window [B:FULL] [C] `code/lib/window_manager_win32.cpp`

**`WinMain`**: stores `HINSTANCE`, `g_windowManager = new WindowManagerWin32()`, calls `AppMain(cmdLine)`, returns `WM_QUIT` [C]. Constructor: `ListAllDisplayModes()`, `SaveDesktop()` (records `ENUM_CURRENT_SETTINGS` width, height, bpp, frequency).

**`CreateWin(w, h, windowed, colourDepth, refreshRate, zDepth, waitVRT, antiAlias, title)`**:

1. Store `m_screenW/H`, `m_windowed`. Register `WNDCLASSW{style=CS_OWNDC, WndProc, icon=IDI_APPLICATION, cursor=IDC_ARROW, background=BLACK_BRUSH, class name = title}`.
2. **Windowed**: `RestoreDesktop()` (if the current display mode differs from the saved desktop mode, `ChangeDisplaySettings(desktop, CDS_FULLSCREEN)`); style `WS_VISIBLE|WS_POPUPWINDOW|WS_CAPTION|WS_MINIMIZEBOX|WS_MAXIMIZEBOX`; `AdjustWindowRect` → `m_borderWidth = (Δwidth)/2`, `m_titleHeight = Δheight − 2·border`; **fail (return false) if the client size exceeds the desktop**; window centred on the desktop rect.
3. **Fullscreen**: style `WS_VISIBLE|WS_POPUP`; `ChangeDisplaySettings({bpp=colourDepth, w, h, freq=refreshRate}, CDS_FULLSCREEN)`; return false unless `DISP_CHANGE_SUCCESSFUL`; position (0,0); `m_borderWidth=1`, `m_titleHeight=0`.
4. `CreateWindowW(class, title, style, x, y, w(+borders), h(+borders+title))`; false on failure; reset mouse offset.
5. `EnableOpenGL(colourDepth, zDepth)` (return value ignored).

`waitVRT` and `antiAlias` are **ignored** by the Win32 GL window manager (`m_waitVRT` never assigned) [C].

**`EnableOpenGL`**: `GetDC`; `PIXELFORMATDESCRIPTOR{PFD_DRAW_TO_WINDOW|PFD_SUPPORT_OPENGL|PFD_DOUBLEBUFFER, PFD_TYPE_RGBA, cColorBits=colourDepth, cDepthBits=zDepth, PFD_MAIN_PLANE}` → `ChoosePixelFormat` + `SetPixelFormat` (results unchecked; no alpha, stencil or multisample bits requested); `wglCreateContext` ×2 — primary `m_hRC` and secondary `m_hRC2` "for loading thread" joined with `wglShareLists` (failure only logged with `FormatMessage`); `wglMakeCurrent(m_hDC, m_hRC)`; `glClear(GL_COLOR_BUFFER_BIT)`. `m_hRC2` is **never made current anywhere** and never deleted (`UseSecondaryContext/ReleaseSecondaryContext/DestroySecondaryContext` are declared but not defined) [C].

**`DisableOpenGL`**: `wglMakeCurrent(NULL,NULL)`, delete `m_hRC`, `ReleaseDC`. **`DestroyWin`**: `DisableOpenGL` + `DestroyWindow`. **`Flip`**: `SwapBuffers(m_hDC)`. **`NastyPollForMessages`**: `PeekMessage/TranslateMessage/DispatchMessageW` loop (called by `W32InputDriver` — P10). `WndProc` forwards to `W32EventHandler::WndProc`, falling back to `DefWindowProcW` when the handler returns −1 or is absent.

**Mouse**: `NastySetMousePos(x,y)` lazily computes the client-origin offset (`GetWindowRect` + border + title when windowed, 0 when fullscreen), `SetCursorPos(x+off, y+off)` and tells `W32InputDriver::SetMousePosNoVelocity(x,y)`; `NastyMoveMouse(dx,dy)` = relative `SetCursorPos` + `SetMousePosNoVelocity(dx,dy)` (passes the *delta* as a position [C]); `CaptureMouse`=`SetCapture`; `UncaptureMouse`=`ReleaseCapture`; `Hide/UnhideMousePointer`=`ShowCursor(false/true)` (OS cursor — the game draws its own, P12 `targetcursor`). `OpenWebsite(url)` = `ShellExecute(NULL,"open",url,…,SW_SHOWNORMAL)` (callers: demo-end window, main menu, script "buy now", `main.cpp`).

**Vsync (GL)**: no `wglSwapIntervalEXT` call exists anywhere [C grep] ⇒ swap interval is whatever the driver default/control panel says; the `WaitVerticalRetrace` preference has no effect in the baseline [C].

**Multisampling (GL)**: none — `wglChoosePixelFormatARB` is loaded but unused; the `antiAlias` argument (always passed `true` by the renderer) is ignored [C].

**Gamma (GL)**: no gamma-ramp code exists for the GL path [C grep `SetDeviceGammaRamp`/`SetGammaRamp`].

### WindowManagerDirectX — Direct3D window [B:D3D] [C] `code/lib/window_manager_directx.cpp`

Same structure as Win32 with these differences: ANSI `WNDCLASS/RegisterClass/CreateWindow/DefWindowProc/DispatchMessage`; icon = resource `MAKEINTRESOURCE(101)`, `hCursor = NULL`; `m_waitVRT = waitVRT` is stored; **`RestoreDesktop` body is commented out** and the fullscreen branch does **not** call `ChangeDisplaySettings` (D3D performs the mode switch); `EnableOpenGL` = `Direct3DInit(m_hWnd, m_windowed, m_screenW, m_screenH, colourDepth, zDepth, m_waitVRT)` + `glClear(GL_COLOR_BUFFER_BIT)`; on failure the window is destroyed and `CreateWin` returns false; `DisableOpenGL` = `Direct3DShutdown()`; `Flip` = `Direct3DSwapBuffers()`; `EnsureMouseCaptured/Uncaptured` overridden as no-ops; `Hide/UnhideMousePointer` only toggle the flag (no `ShowCursor`); destructor also `m_resolutions.EmptyAndDelete()`. `WinMain` additionally handles `TARGET_OS_VISTA` (`-mediacenter` → `g_mediaCenter=true` + `Sleep(7500)`; otherwise a save-file path argument → `g_saveFile`, `SetCurrentDirectory(exe dir)`) — `TARGET_OS_VISTA` is never defined ([B:DEAD]). Title parameter type mismatch: see build-viability note in 24.

### Window creation fallback chain and resolution switching [C] (code in P12/P17b files, behaviour owned here)

`Renderer::Initialise` (`code/renderer.cpp`) reads preferences, then:

| Attempt | Parameters | On failure |
|---|---|---|
| 0 (first run) | if `ScreenWidth`=`ScreenHeight`=0 → `SuggestDefaultRes` (desktop w,h,refresh,depth) and save to prefs | — |
| 1 | `GetClosestResolution(w,h,refresh)`; `CreateWin(w,h,windowed,depth,refresh,zDepth, waitVRT=true, antiAlias=true, L"Multiwinia")` | show `MessageDialog("Error", "Failed to set requested screen resolution of …")` at (100,100) and continue |
| 2 | desktop default res/refresh/depth, `zDepth=24`, `waitVRT` variable set 0 (but literal `true` still passed) | — |
| 3 | 800×600, windowed, 16-bit colour, 16-bit z, 60 Hz, `waitVRT` (=0) | — |
| 4 | same with 24-bit z | `AppReleaseAssert("Failed to set screen mode")` |

Afterwards all screen prefs are written back and saved; `InitialiseOGLExtensions()` and `BuildOpenGlState()` follow. Note that attempts 1–2 pass the literal `true` for `waitVRT`, so the `WaitVerticalRetrace` preference only matters on attempts 3–4 (and only in the D3D build) [C].

`RestartWindowManagerAndRenderer()` (`code/interface/prefs_screen_window.cpp`, used when applying screen options and by `SetWindowed`): records old size; if currently fullscreen and staying fullscreen (`hack`), first creates and destroys a temporary **640×480 windowed** renderer/window ("necessary for resolution change in fullscreen"); `DestroyWin()`, `delete m_renderer`, new `Renderer` + `Initialise()`, then `Resource::FlushOpenGlState()` + `RegenerateOpenGlState()` (all textures and display lists rebuilt), clear to black, reposition UI windows. On `TARGET_OS_LINUX` a "Restart Required" dialog is shown instead [B:DEAD].

### Gamma [B:D3D] [C]

`Renderer::SetScreenGamma(gamma)` exists only under `USE_DIRECT3D`: exponent `g = 2.0 − gamma`; ramp `red[i]=green[i]=blue[i] = iv_pow(i/255, g) · 65535` for i = 0..255; `g_pd3dDevice->SetGammaRamp(0, 0, &ramp)`. **No caller exists** [C grep] ⇒ gamma control is dead in both builds.

### Video capture — `AVIGenerator` [B:DEBUG] [C] `code/lib/avi_generator.*`

Compiled only with `AVI_GENERATOR`, which only `TARGET_DEBUG` defines (and Linux/Mac `#undef`) [C] `code/lib/universal_include.h`. Based on Jonathan de Halleux's CodeProject "AVIGenerator" (header comment) using Video for Windows (`vfw.h`).

| Member | Behaviour |
|---|---|
| ctor | `m_motionBlurFactor = pref AVIMotionBlurFactor (1)`; `m_frameRate = pref DemoFrameRate (25) / m_motionBlurFactor`; `BITMAPINFOHEADER{size, w=ScreenW, h=ScreenH, planes 1, 24 bpp, BI_RGB, biSizeImage 0, 1000 ppm ×2}`; output file `"Untitled.avi"` |
| `InitEngine()` | requires VfW ≥ 1.10 (`VideoForWindowsVersion`), `AVIFileInit`, `AVIFileOpen(OF_WRITE|OF_CREATE)`, video stream header (`dwScale=1`, `dwRate=frameRate`), `AVIFileCreateStream`, `Setup()` = **interactive `AVISaveOptions` codec dialog**, `AVIMakeCompressedStream`, `AVIStreamSetFormat(m_bih)`; allocates `m_pixels` and `m_accumBuffer` of `w·h·(biBitCount / sizeof(unsigned char))` = `w·h·24` bytes (8× larger than needed); error strings in `m_error` |
| `AddFrame()` | `glReadPixels(0,0,w,h,GL_RGB)`; motion-blur accumulation: on frame `k % factor == 0` the accumulator is overwritten with `pixel·(1/factor)` (BGR swizzle), otherwise added; on `k % factor == factor−1` writes the accumulator via `AddFrame(bits)` |
| `AddFrame(bits)` | `CheckSanity()` (filename ends in "avi", w and h multiples of 4 — debug asserts), `AVIStreamWrite(compressed, outFrame++, 1, bits, biSizeImage (=0), AVIIF_KEYFRAME)` |
| `ReleaseEngine()` | release streams/file, free buffers (`delete` on arrays), `AVIFileExit` |
| dtor | if pref `RecordDemo == 2` → `ReleaseEngine()`; asserts all released |
| `GetRecordingFrameRate()` | `m_frameRate` |

Integration [C]: created by the debug **Grabber** window (`code/interface/grabber_window.cpp`, opened from `DebugKeyBindings::GrabberButton` in `code/interface/debugmenu.cpp`): *Start* sets fake-time mode and calls `InitEngine`; *Stop* restores real time and releases. `UpdateAdvanceTime` (`code/main.cpp`) uses a fixed step `1/DemoFrameRate` when pref `RecordDemo` is 1 or 2. **No code calls `AVIGenerator::AddFrame()`** [C grep] — in this tree a recording produces an AVI with no frames. `RecordDemo == 1` additionally saves `serverHistory.dat` on game shutdown (`App::ShutdownCurrentGame`, `main.cpp`) — P15/P20.

### Video playback — `AviPlayer` [B:DEAD] [C] `code/lib/avi_player.*`

Guarded by `EGAMESBUILD` (never defined; consumer `code/loaders/egames_loader.cpp`). `OpenAvi` opens video stream 0 + audio stream 0 via VfW, begins streaming at speed 2000, allocates a fixed **512×256×3** RGB frame buffer; `DecodeVideoFrame(int)` copies the DIB from `AVIStreamGetFrame` into the POT buffer with BGR→RGB swizzle (row stride 512·3; returns 1 at end, 0 otherwise, counts displayed/missed frames); `DecodeVideoFrame(float t)` → `AVIStreamTimeToSample(t·1000 ms)`; `GetAudioData(n, short*)` reads n PCM samples sequentially; `CloseAvi` releases everything. → Appendix only.

## [→ 31_platform_build_and_tools] 31.3 Timing — `hi_res_time`

API [C] `code/lib/hi_res_time.h`: `InitialiseHighResTime()`, `double GetHighResTime()` (seconds), `SetFakeTimeMode()`, `SetRealTimeMode()`, `IncrementFakeTime(double)`.

Mechanism [C] `code/lib/hi_res_time.cpp`:

1. `InitialiseHighResTime` reads `QueryPerformanceFrequency` and stores `g_tickInterval = 1/freq` (seconds per tick). Called once from `code/main.cpp:Initialise`, *after* `new SystemInfo` and before any timing use [C].
2. `GetLowLevelTime()` (QPC path, `USE_PENTIUM_COUNTER 0`): on first call latches `startTime = QPC`; returns `(QPC − startTime) × g_tickInterval`. Time therefore starts at **0.0 s on the first query** (process-relative), resolution = 1/QPC-frequency (typically 0.3–1 µs on 2008 hardware [I]). No wrap handling is needed (64-bit counter).
3. `GetHighResTime()`: if fake mode, returns `g_fakeTime`; otherwise `GetLowLevelTime() − g_timeShift`. A disabled block (commented) once clamped jumps > 1 s. No monotonicity guard: cross-core QPC skew would surface directly [I].
4. Fake time: `SetFakeTimeMode()` freezes `g_fakeTime = GetHighResTime()`; `IncrementFakeTime(dt)` advances it; `SetRealTimeMode()` sets `g_timeShift = realTime − g_fakeTime` so real time resumes continuously from the fake value. Used for offline frame-exact capture: AVI grabber window (`code/interface/grabber_window.cpp` toggles modes [B:DEBUG via AVI_GENERATOR]) and demo/AVI recording advancing `1.0/DemoFrameRate` per frame (`code/main.cpp` `IncrementFakeTime( 1.0 / (double)demoFrameRate )`, pref `DemoFrameRate` default 25) [C].
5. RDTSC path (`GetPentiumCounter`, inline asm `0F 31`, keeps bits 6..37 of the TSC; calibrated against QPC with a 1 s `Sleep`) is compiled out (`#define USE_PENTIUM_COUNTER 0`) [C] [B:DEAD].

Variants: `code/lib/hi_res_time_gcc.cpp` (QPC, *absolute* counter, no first-call latch) and `code/lib/hi_res_time_sdl.cpp` (`gettimeofday` relative to first call, µs resolution) [C] [B:DEAD].

Design notes for the new engine: keep a single monotonic clock (`QueryPerformanceCounter`/`std::chrono::steady_clock`) relative to process start, with an injectable fake clock for capture/replay; simulation time must never be derived from it directly (simulation ticks are driven by the network/game timer, P01/P15).

### 31.5.2 Archive semantics [C] `code/lib/resource.cpp:Resource::ParseArchive`, `contrib/unrar/unrar.cpp:MemMappedFile::MemMappedFile`, `contrib/unrar/unrar.h`

* A missing archive is silently skipped (`DoesFileExist`). Exceptions during decompression → archive ignored.
* The **whole archive is decompressed into memory** at load (`UncompressedArchive`); max `MAX_FILES = 16384` entries per archive.
* Entry names: `\` → `/` then `strlwr` (lower-case). **Zero-byte entries are dropped** (`m_size > 0` test).
* **Later archives override earlier ones** with the same name (old `MemMappedFile` deleted). Effective precedence: `sounds2 > sounds > branding > menusounds > patch > main > language > init`.
* Lookups are under a `NetMutex` (archives are parsed on worker threads).
* Unrar is not thread-safe, so sound archives are parsed on a dedicated serial worker queue on PC (`App::m_soundsWorkQueue`) [C] `code/app.cpp` comment "Can't unrar too files at once".

### 31.5.3 Lookup precedence for a resource name `N` [C] `code/lib/resource.cpp:GetTextReader/GetBinaryReader`

1. (`USE_DARWINIA_MOD_SYSTEM` only, [B:DEAD]) `<P>mods/<mod>/N`, then (Vista) `mods/<mod>/N`.
2. **Loose file `data/N`** (relative to cwd) — UTF-16 BOM → `UnicodeTextFileReader`, else `TextFileReader`; binary → `BinaryFileReader`.
3. Archive entry `data/N` (exact string; archive keys are lower-case, so callers must pass lower-case names) — BOM → `UnicodeTextDataReader`, else `TextDataReader`; binary → `BinaryDataReader`.
4. Not found → `NULL` (+ `AppDebugOut("Failed to find text resource…")`).

Consequence: loose `data/` always beats archives, which is how the development tree runs without archives and how users can override files [C].

**Important ordering consequence [I, strong]:** `PrefsManager` is constructed right after `init.dat` is parsed and **before** `main.dat` (`code/app.cpp:App::App`). On first run its `CreateDefaultValues()` looks up `default_preferences.txt`, which is not in `init.list` and so lives in `main.dat` in a packaged build; in a packaged install the file is therefore not found and only the hard-coded defaults apply (in the development tree the loose `data/default_preferences.txt` is found).

### 31.5.4 SystemIV `FileSystem` (compiled, unused)

`contrib/systemiv/lib/filesys/file_system.cpp:FileSystem` provides the same idea (search paths → raw path → archive BTree) but `g_fileSystem` is never instantiated by Multiwinia; only non-compiled SystemIV modules (`lib/sound`, `lib/resource`) use it [C] (grep: no `new FileSystem` in `code/`) → [B:FULL compiled, unreachable]. Quirks if re-used: archive lookup is case-sensitive on the requested name; `ListArchive` ignores `fullFilename` for archive results and its `OrderedInsert` never compares against the last element (duplicates possible) [C] `FileSystem::ListArchive`, `OrderedInsert`.

## [→ 31_platform_build_and_tools] 31.10 ShapeExporter (3ds Max → `.shp`)

`tools/ShapeExporter/*` is a 3ds Max 5 SDK `SceneExport` plugin (`ShapeExporter.dle`, extension `shp`, "Futurewar Shape Format v1.0", ClassID `0x3288038e,0x40eff553`) [C] `tools/ShapeExporter/ShapeExporter.cpp`.

Algorithm [C] `ShapeExporter::DoExport/ExportNode/ExportMesh/ExportMarker/BuildShapeFragment`:

* Root `ShapeFragment("scene root")`; for each child of the Max root node, `ExportNode(node, root, depth=1)`; abort recursion of a subtree on failure.
* Only `GEOMOBJECT_CLASS_ID` nodes (targets skipped). Node names starting with `marker` (case-insensitive) → `ShapeMarker(name, parentName, depth, localTM)`; others → mesh fragment (converted to TriObject; empty meshes skipped) whose children are recursed with `depth+1`.
* Local transform = `nodeTM × inverse(parentTM)` at time 0; **axis conversion Max (x,y,z) → game (x, z, −y)** for positions and the right/up rows; the front row is converted as `(−f.x, −f.z, f.y)` for fragments but `(f.x, f.z, −f.y)` for markers (sign inconsistency); matrices normalised.
* Positions de-duplicated with squared-distance threshold `0.001² = 1e-6`; colours de-duplicated exactly on RGB (per-vertex colours ×255, else material diffuse, else node wire colour); vertices = unique (posId, colId) pairs; triangles copied from Max faces (no stripping despite including NvTriStrip).
* Output written by the engine's own `Shape::WriteToFile` (text `.shp`, grammar owned by X1b/P12).
* The VC6 projects reference `code/lib/{debug_utils,text_stream_readers,…}.cpp` that no longer exist → the exporter cannot be rebuilt from this tree [C absence]; the prebuilt `tools/binaries/ShapeExporter.dle` remains.

## [→ 31_platform_build_and_tools] 31.13 Crash handling

Three independent mechanisms, all [B:FULL] (`USE_CRASHREPORTING` global, `TARGET_MSVC`):

### 31.13.1 SEH crash report (`RecordExceptionInfo`)
`code/main.cpp:AppMain` wraps the whole game (`RunTheGame`) in `__try { … } __except( RecordExceptionInfo( GetExceptionInformation(), profile, "AppMain", "0B9432AF", DARWINIA_VERSION ) )`, where `profile` = profile directory captured before running [C]. Only the main thread is covered; worker threads (`WorkQueue`, network) have no SEH wrapper [I: no `__try` in `code/lib/work_queue.cpp`, `net_thread_win32.cpp`].

`code/lib/exception_handler.cpp:RecordExceptionInfo` (Bruce Dawson / Hans Dietrich XCrashReport derivative) [C]:
1. Re-entrancy guard (`static bFirstTime`) → second call returns `EXCEPTION_CONTINUE_SEARCH`.
2. Log path = `<profile>ERRORLOG.TXT` (exe directory if profile empty); opened `CREATE_ALWAYS|WRITE_THROUGH`, then seek to end ("append", effectively overwrite because of CREATE_ALWAYS [I]).
3. Writes (no CRT, `wvsprintf` via 8 KiB buffered `hprintf`): header `"<exe> caused <description> (0x%08x) in module <module> at %04x:%08x"`; `"Exception handler called in AppMain."`; system info: **crash reference code** = low 32 bits of current FILETIME in hex (`_ltot_s` base 16), local time, exe path + Windows user name, `GetWinVer` OS name and `major.minor.build`, processor count/type, memory load %, physical/page/virtual totals and free (MB, rounded up); for access violations `"Read from"/"Write to location %08x"`; registers EDI ESI EAX EBX ECX EDX EIP EBP SegCs EFlags ESP SegSs; 16 code bytes at EIP (`??` if unreadable); stack dump from ESP up to the TIB stack top (`fs:[4]`), max 3072 DWORDs, 4 per row with ASCII; module list by walking the 4 GiB address space with `VirtualQuery` and printing for each loaded image: path, image base/size, checksum, timestamp, file size/time, version info (company, product, description, file/product version via `CMiniVersion`); trailer `===== [end of ERRORLOG.TXT] =====`.
4. Minidump `<profile>CRASH.DMP` via `MiniDumpWriteDump(..., MiniDumpWithIndirectlyReferencedMemory, …)` (`XCRASHREPORT_WRITE_MINIDUMP 1`).
5. If a debugger is attached → `EXCEPTION_CONTINUE_SEARCH`. Else launch `MultiwiniaSupport.exe` (exe directory) with command line `<exe dir>\MultiwiniaSupport.exe "<exe file name>" <crashID> 0B9432AF dev "<profile dir with every \ doubled>"` (the support-tool path itself is **not quoted**; `CreateProcess(NULL, cmdline, …)` must then resolve a path containing spaces heuristically); success → `EXCEPTION_EXECUTE_HANDLER` (suppresses the Windows dialog, process ends), failure → `EXCEPTION_CONTINUE_SEARCH`.

Exception descriptions table (24 codes) [C] `GetExceptionDescription`: 0x40010005 Control-C, 0x40010008 Control-Break, 0x80000002 Datatype Misalignment, 0x80000003 Breakpoint, 0xC0000005 Access Violation, 0xC0000006 In Page Error, 0xC0000017 No Memory, 0xC000001D Illegal Instruction, 0xC0000025 Noncontinuable Exception, 0xC0000026 Invalid Disposition, 0xC000008C Array Bounds Exceeded, 0xC000008D Float Denormal Operand, 0xC000008E Float Divide by Zero, 0xC000008F Float Inexact Result, 0xC0000090 Float Invalid Operation, 0xC0000091 Float Overflow, 0xC0000092 Float Stack Check, 0xC0000093 Float Underflow, 0xC0000094 Integer Divide by Zero, 0xC0000095 Integer Overflow, 0xC0000096 Privileged Instruction, 0xC00000FD Stack Overflow, 0xC0000142 DLL Initialization Failed, 0xE06D7363 Microsoft C++ Exception; otherwise "an Unknown exception type".

### 31.13.2 Support/crash reporter (`MultiwiniaSupport.exe` + `MultiwiniaSupport.ini`)
Prebuilt binary `tools/multiwiniasupport/MultiwiniaSupport.exe` (strings reference `crashreports.introversion.co.uk`) [C].
