## How to read this matrix

Every file in the `multiwinia/` tree (6,189 entries) has one row, grouped by area:

| Column | Meaning |
|---|---|
| **Path** | Path relative to the `multiwinia/` source root at commit `f909630`. |
| **Build** | `live` = compiled into the PC project (listed in `targets/vs2005/Darwinia.vcproj` or `contrib/eclipse/eclipse.vcproj`, not excluded in all configurations) **or** `#include`d by such a file (manifest column `included_by_live`); `excluded` = listed but excluded in every configuration; `not-in-project` = source file the project never compiles; `n/a` = data, docs, tools and other non-source files. |
| **Cited in** | Final documents (by number) that cite the file with a `path:Symbol` or path reference. 91 and 99 themselves are not counted. |
| **Depth (agents)** | Deepest read recorded in any coverage fragment (`full` / `skimmed` / `not-read`) and the Phase-2/3 agents that recorded it. |
| **Out-of-scope justification** | Why a file needs no citation (third-party library internals, uncompiled SystemIV components, dead platform code), from `_work/out_of_scope.csv` or the automatic rule for non-compiled source. |
