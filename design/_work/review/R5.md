Implementability gaps: **High 0 · Medium 5 · Low 16** (21 in total).

The three most serious findings:

1. **30 §2.3 / §2.4: the description of script waits is wrong.** The doc says that "consecutive waits take the max, they do not add" and that "several waits can be armed by consecutive lines and are satisfied jointly". In the code, every blocking wait stops the next line from being read until its condition holds, and all wait flags are cleared before the next line runs. Waits therefore **add**, and they are satisfied **one after another**. The `max()` in `RunCommand_Wait` has no practical effect (`code/script.cpp:296-300`, `:636-731`). The pseudo-code in the doc is correct; only the stated consequences are wrong. A script author would time cutscenes wrongly.
2. **30 §3.4: two tutorial AI rows contradict the code and 07 §17.**
   - "CPU creates officers: never" is wrong. Only `AI::AdvanceOfficerAI` returns in a tutorial (`code/worldobject/ai.cpp:1136`). The goto-officer path at spawn points in `AI::AdvanceMultiwiniaAI` has no tutorial check (`ai.cpp:638-713`).
   - The "CPU radar use" rule is incomplete. Dishes outside {7, 9, 10, 12, 13, 15} are only skipped when their nearest node is owned by another team, or by the CPU itself with more than 30 friends (`ai.cpp:1039-1064`).
3. **Build tags for loader-era code disagree between documents and with the tag definitions.**
   - `StartSequence` is tagged [B:DEAD] in 10 §6.3 and in 27 (§2.4, Source map, Appendix). It is [B:LEGACY] in 06, 09, 24 and 30, which is what the code supports: `startsequence.cpp` is compiled (`targets/vs2005/Darwinia.vcproj:10044`, no `#ifdef`) and only `RunBootloader` (inside `USE_LOADERS`) constructs it (`code/main.cpp:1233-1248`).
   - 27's Appendix lists `Credits` under "[B:DEAD] (`USE_LOADERS`)". `CreditsLoader` is in fact compiled outside `USE_LOADERS` (`code/loaders/loader.cpp:108`) and is reached from `Camera::AdvanceSphereWorldOutroMode` (`code/camera.cpp:506-509`) and from the script op `RunCredits`. That makes it [B:LEGACY], which is how 10 §6.3 tags it.
