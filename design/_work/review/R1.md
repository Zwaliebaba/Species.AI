Implementability gaps: **28**. High 1, Medium 9, Low 18. Cross-document inconsistencies: 12.

Overall the three documents are accurate. Every load-bearing formula I checked matched the code exactly, including spawn ownership, activation, burst/pause, handicap, transit, the population cap, the trunk-port wave algorithm, the spirit timers, the harvester rules, and the Domination, KOTH, CTS, Assault, Rocket Riot and Blitzkrieg per-second logic. The float-accumulation tick counts were also right: 11, 61, 101, 151, 300, 450, 901, the 649/660 and 324/330 waves, the 21-tick freeze, the 200-tick countdown and the 176–248 flight ticks.

**Three most serious findings**

1. **"5 Darwinians per port" (High).** 05 §9 (the compact re-implementation reference), 05 §1.1 and 00 §3.2 say "5 per port". The code seeds **one Darwinian per port**, which is 5 per SpawnPoint or SolarPanel (`code/location.cpp:3357-3372`). 05 §6.7 and the §4.6 table say this correctly. Anyone coding from §9 or 00 would start each team with five times too many seeded Darwinians.
2. **Cross-document contradictions in the core economy.**
   - 03 §4 says spawn-network transit is "exactly 1.0 s per link". 05 §3.4 and the code give 11 ticks for the first link and 10 for each later one.
   - 00 Q4 calls the harvester "the only population source that ignores the cap". 05 §4.3 and the code also list the Darwinians crate, triffid eggs, the incubator, rocket ejection and conversions (`code/worldobject/crate.cpp:1946-1958`).
   - 00 §3.2 and Q5 state the handicap without its "no neutral spawn point" precondition (`code/worldobject/spawnpoint.cpp:1173`).
3. **Rule mis-statements in 01.**
   - The CTS fallback "winningTeam == −1 (no used teams)" is also reachable on a tied time-up when every team is soft-eliminated (`code/multiwinia.cpp:1376-1397, 1436`).
   - The tutorial-override row is wrong. Basic crates, CrateDropMode 0 and **Standard** AI are applied only at Tutorial 2's End step; Easy AI comes from `GameMenuWindow::SetupTutorial*`. This contradicts 09 and 30.
   - The Assault "900 s / 1200 s" bomb clock counts **mode seconds**, so it runs 990 / 1320 game seconds (`code/multiwinia.cpp:1770`).
