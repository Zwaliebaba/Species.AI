# M1

The record of milestone M1 (README, "A milestone record"): the battle sandbox (`Design/implementation/mvp_scope.md` §3, MVP-002), in the tasks of `Design/implementation/m1_plan.md`. Each exit criterion is listed below with the evidence it has and what it still needs; the build that met them all is named here when the milestone ends.
