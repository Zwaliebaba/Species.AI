Main observations:

- **No original product, character or place name** was found in scope apart from the mode description of finding 18. The achievement names, "ant", "Skill rating" and the names used only in Dropped decision entries are registered in CONVENTIONS §8.
- **Conversion internals** remain in CONVENTIONS (the status line and §8 cite the run's phases, ledger and agent reports), in two reference documents (the ledger), and as unregistered `FX-NN` and `KH-MUSIC` labels in the audio documents.
- **Reference-code narration** is concentrated in `reference/08_maps_and_level_design/map_editor_hooks.md` (memory-safety defects, loader internals) and `reference/12_simulation_model/07_randomness_and_integrity.md`, which is built as a register of the reference implementation's integrity violations (thread races, render code that writes simulation fields, function-level statics). These are the High findings 61, 62, 126 and 127.
- **Species production planning** (the first playable of owner decision O20, the build order of DEC-229, the tutorial plan of DEC-123) is written into reference rules in 01, 05, 07, 08, 10, 11 and 12.
- **Legacy technology**: display modes with colour and depth bit depths, a software mixer with an 11 025 to 44 100 Hz mixing-rate setting and hardware positioning, the DirectSound standard effect set (DMO parameters, I3DL2) mirrored as Species XAPO names, and the C runtime `rand()` generator as the tree generator.
- **Dead code**: research levels that a match fixes, campaign records and an unreachable editor, the mortar turret, commands, bindings, cursors, messages and assets that no match reaches, and a superseded voice allocator that is still a MUST requirement (finding 91).
