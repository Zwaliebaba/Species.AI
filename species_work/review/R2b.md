# R2b: cleanliness review

Reviewer R2b (cleanliness), Phase 5. Scope: `design_next/architecture/` (every file), `design_next/ADR/`, `design_next/decisions/` (with `deferred/`), `design_next/assets/` (GameAssets.md, README.md, art_and_audio_briefs.md and a scan of asset_manifest.csv), plus `AGENTS.md`, `CLAUDE.md`, `vision/`, `prompts/species-design-phase.md`, `Tools/DesignCheck/README.md` and `Tools/DesignModels/README.md`.

Method: every in-scope file was read in full (the manifest was scanned column by column). The source corpus `design/` and the ledger were not opened. No repository file was edited; the only other file written is the reading aid `species_work/scripts/R2b_scan.py`. File paths are given from the repository root; `design_next/` becomes `Design/` at the cutover. No original product, character or map name appears in this file.

What was deliberately not flagged: the sanctioned "Reference behaviour" and "lessons" sections of the deferred decisions (only legacy technology, wire layouts and provenance in them are flagged), ADR amendment notes (unless they cite conversion internals or are stale against an owner decision), and the description of the cutover in `AGENTS.md`, `CLAUDE.md` and the vision (flagged only where it is wrong after the cutover).
