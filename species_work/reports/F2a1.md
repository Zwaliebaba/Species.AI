## Conventions I applied

- **Mixed tables.** Where a table mixed actions, I split it by rows below H3: 00 §2.3, §2.5 and §7; 01 §3.5 and §6. The anchor is still the containing heading.
- **H2 heading lines.** The heading line of an H2 that is split at H3 has its own row. It is `DROP-PROVENANCE`/`DP-INDEX` when the H2 has no intro text. When the next row continues the same target, the heading is included in that row.
- **Open questions.** These sections are routed `TO-DEC` alone; I did not add a `DP-CLOSING` row over the same range, so that only the overlap pairs the coverage rule allows are used. The note on each lists which items need no DEC (legacy, test maps or resolved).
- **Legacy content inside KEEP sections.** Legacy states, rows and debug rows are left inside their KEEP ranges and named in the note, for example "drop [B:LEGACY] single-player states". The rewrite agents drop them by build tag.
