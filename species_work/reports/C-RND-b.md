## New DEC requests

1. **Lighting of the scaled centipede segment.** The reference draws centipede segments scaled by their size without renormalising normals, so a segment at scale σ is lit with n ÷ σ (darker when larger, brighter when smaller, before the clamp). RND-326 states this as the reference default, an exception to RND-055. Options: A — keep; B — unit normals. The input does not say whether ants (scaled by their scale) renormalise; I kept unit normals for them. C-RND-a's quirk 5 (walls) is the same question.
2. **Crawler egg blob-shadow size.** The input gives the egg a blob shadow but no size. RND-324 uses the card's half-size (`ref.unit.crawler_egg.card_size` ÷ 2 = 4 wu) as a stated default. Needs an Open DEC (or a value from G02b).
3. **Route-line spot spacing and arrows.** The input gives the spot size (camera distance ÷ 100) and the per-spot pulse phase, not the spacing, and names an arrow texture without placement. RND-353 places spots one spot size apart and leaves the arrows to the design phase (§8 input 4). Needs an Open DEC with that default.
4. **Order of the marker alpha rules** (now G06's R-CTRL-384): the rules are listed without an order of application; applying the distance and centre floor before the transient 2 s fade makes a transient marker vanish at 8 s, matching `ref.power.marker.lifetime_s`. Confirm as an Open DEC or a note in G06.
5. **Frame-rate-dependent selection-circle particles** (G06's R-CTRL-370): 30 control-flash particles are created per rendered frame, so the circle's particle density grows with the frame rate. Options: A — keep; B — a per-second emission rate (ADR-0036 accumulates per event, not per frame).
6. **State leaks between actor draws.** The reference lets each actor in passes 7a and 7b inherit the state the previous actor left (for example blend left on after an Abductor beam or a barrage missile), which makes some lit meshes blend in an order-dependent way. The input itself recommends explicit full state per draw; RND-303 states that fixed rule. Please add a Resolved DEC (or extend DEC-029) to record it.
7. **Smaller interpretation points, low priority** (confirm or note): the lightning strike's alpha |sin(λ − t)| with t the extrapolation time, and its bolt quads in the `UprightCard` mode (RND-337); the "vertical ×2" of the blur kernel, written as the vertical pass applied twice (RND-422).

## ADR conflicts and requests

1. **ADR-0005 blend list lacks "one, source colour".** Same as C-RND-a item 2: the placement ghost models need it (`Ghost`, RND-058, RND-365). ADR-0005 needs an amendment.
2. **ADR-0018 blend pairing.** The reference draws marker, cursor, compass and Power icons additively (source alpha, one) over darkened shadows, while the manifest tags them straight alpha, and ADR-0018 makes straight alpha with any blend other than `Alpha` a build error. RND-393 and RND-423 keep the additive look with real alpha channels. ADR-0018 needs to allow straight-alpha art with the `Additive` blend, or X-AST must tag those assets `additive`.
3. **ADR-0018 derived variants versus the manifest.** `cursor.world`'s spec says "blurred darkening shadow generated at run time"; ADR-0018 and RND-243 produce blurred shadows offline in the cooker. RND-366 and RND-422 follow the ADR.
4. **ADR-0009 instance layout.** The `Segment` orientation mode needs a colour per end (Crawler strips, RND-319), and the `WorldOriented` mode carries the billboard blend start and length (RND-306). Both fit the ADR; the shared `QuadInstance` layout in shaders.md RND-262 should list these fields.
5. **Defaults the ADRs leave open**, set here: present mode vertical sync (matching README `RenderConfig`), brightness 1, HDR highlight limit the display's maximum (RND-442).
