## Notes for the coordinator

1. **DEC-221 residue.** DEC-221 (`process_tick_and_roadmap.md`) still narrates the reference's code in the lessons of items 2, 3, 6, 7, 8 and 10, for example "pointer members that the first construction phase does not set stay indeterminate", "one destructor busy-waits" and "the path helpers … write into one static buffer". V2 did not list it, and only item 9 was changed here, because DEC-222 cites it. Under ruling 3 those lessons would become the Species rules or observable behaviour; the items keep their numbers, because UI, AEN and R-SIM cite DEC-221 items 3, 4 and 7.
2. **Seen, not changed: the colour type in the shared header.** shaders.md RND-262 says "a colour is a `Uint32` holding 8-bit red, green, blue and alpha". Yet `DrawConstants::tint` is a `Float4`, and the `FrameConstants` fog and light colours are `Float3`, which they must be, because a seasonal light colour of 1.3 exceeds 1. The sentence could read "an 8-bit colour of an instance record is a `Uint32` …". This is outside the V2 items.
3. **Seen, not changed: ADR-016's packing keyword.** ADR-016 says that HLSL "declares them `row_major`", while RND-260 packs with `-Zpr`, so the header needs no keyword. The two agree in effect but not in wording.
