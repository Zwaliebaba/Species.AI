## New DEC requests (all Open; the default is the reference behaviour, already stated as the rule)

1. **Crawler bite cadence** (R-UNIT-532). A Crawler in contact bites for 20 every tick (200/s) while no other enemy is 30–60 wu away. Options: A, keep it; B, a bite cooldown. This value is design-critical and derived from the search rule.
2. **Spider avoidance neighbour draw** (R-UNIT-576). For each detected spider, the escape vector uses the neighbour at index `NextUint mod n`, not the spider that was found. Options: A, keep it; B, use the detected spider.
3. **Abductor double time step** (R-UNIT-705). The position advances by speed × dt × dt, so the effective speed is a tenth of the speed value. Options: A, keep it, as the default the README already reflects in its speed of 244; B, a single step with the speed re-tuned to the same effective timing. This could instead amend DEC-090.
4. **Barrage missile self-kill credit** (R-UNIT-726). Every kill of the barrage counts for the launching team, its own losses included, unlike the general rule R-UNIT-032. Options: A, keep it; B, count enemy kills only.
5. **Barrage missile ignores its own death** (R-UNIT-723). At 0 health it releases an orb and keeps flying. Options: A, keep it; B, remove it when destroyed.
6. **Creature presentation quirks**, as one entry:
   - the Bomber's shatter fraction is computed against 255 health (R-UNIT-718);
   - every Reaper Serpent hit shatters every tail segment (R-UNIT-593);
   - Crawler eggs are drawn white whatever their team (R-UNIT-528);
   - all Brood Drifters share one smoothed tail velocity (R-UNIT-547).
   Default: keep.
7. **Reaper Serpent fallback roam range** (R-UNIT-520). The input gives the kind-0 Crawlers 100 wu in the release table but says 200 wu in the Reaper Serpent text. I specified 100 wu, the kind-0 value, because the fallback runs kind 0. The owner should confirm.
