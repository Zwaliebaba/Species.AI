## How the brief's special points were handled

- **Perfect information.** README §2.5 states plainly that bots have no fog of war, no sensing radius beyond named query radii and no reaction delay beyond their periods; table 2.5-A lists every kind of perfect-information read (map-wide versus around own units), and each rule that makes one is marked. The reference behaviour is unchanged.
- **Commands (DEC-119).** README R-BOT-014 makes a bot an authorised command source: `TargetPower`, `CancelPower` and `AimBeamDish` are issued as catalogue commands that execute at once inside the bot's step (reference timing, R-SIM-435) and never enter the batch. Table 2.4-A marks every other reference bot action (per-Worker waypoint orders, Leader orders and formations, Transport, Strike team, Collector, Builder and Breach Charge control, starting a promotion Power) as **bot-only**, because no catalogue command expresses it; see DEC request 1.
- **Unit policies.** The Transport, Strike team, Leader, Collector, Builder and Breach Charge bot behaviours are already specified with the units (G02a1, G02a2, G03a); this folder links them (04 table of R-BOT-125) and specifies only the bot-side rules they use (target selection, predicates, Siege objective state, field list), as G02a2 asked.
- **DEC-087 corrections** are stated as the fixed rules and listed in README §5 item 8.

## New DEC requests

1. **Bot actions outside the player command catalogue** (R-BOT-014, R-BOT-015, table 2.4-A). DEC-119 makes bots command sources; the reference bot also acts through operations that have no command. Options: A — keep them as bot-only operations with an existence-and-team check (default); B — add bot-usable commands (per-actor waypoint order, Leader orders and formation, Transport arrival point, Breach Charge route, start a promotion Power); C — restrict bots to the existing catalogue. Decide by: design phase.
2. **Bot controller position** (R-BOT-008). DEC-087 places it "inside the map" without a position. Default chosen: the team's start position, or the map centre for the Rogue and Visitor factions; no spawn search, no draws. Interactions: it adds one body to the head count of nearby nodes (01 §5 item 8), and enemy Workers can target it (DEC-311 default). Please confirm in DEC-087 or open a DEC (options: A — as chosen; B — a point outside every node's range; C — no spatial body, DEC-311 option C).
3. **Promotion Power expiry** (R-BOT-107). DEC-087 says unused Leader powers expire; default chosen: at the end of the bot step that started the Power. Please confirm in DEC-087.
4. **Standard priority with no usable link** (R-BOT-060, R-BOT-071). Default chosen: the neighbour mean is 0 (the bonuses still apply). Please confirm in DEC-087/DEC-653 item 6.
5. **Bounded placement loops** (R-BOT-105, R-BOT-117). Cap 100 draws (`ref.bot.power.placement_attempts`, equal to the reference's own random-selection cap), fallback "nothing placed this cycle, the Power stays Waiting". Please confirm in DEC-014 (G02b raised the same kind of item).
6. **Defence-flag propagation** (R-BOT-129). The single pass marks a defence chain longer than two to its end only when its objectives come in chain order in structure order. Quirk not covered by a Resolved DEC: Open, A — keep (default); B — propagate to the chain end.
7. **Tagged zone never cleared** (R-BOT-036). A node keeps its Control Zone or Relic Spawn Zone tag after capture. Open, A — keep (default); B — retag at every rebuild.
8. **Worker nearest node never cleared** (R-BOT-043). A Worker can be dispatched only from a node that once was nearest to it. Open, A — keep (default); B — recompute at every recount.
9. **Pins on a shared nearest node** (R-BOT-070). The last writer in structure order wins. Confirm under DEC-016 or open a DEC.
10. **Random selection and stored crossings** (R-BOT-088). Random selection re-draws on any other team's emitter, switched on or off; with DEC-087's state-independent crossings it now also avoids links that cross a switched-off foreign emitter that the reference link build did not record. Please confirm that this consequence is intended.
11. **DEC-087 / DEC-112 wording.** "An active Siege bot Transport behaviour, which never runs in the reference": only the mobile-bomb branch (transport.md R-UNIT-405 item 1) was unreachable, because the Transport objective list stayed empty; R-BOT-127 fixes the list. transport.md R-UNIT-405 says "The Siege behaviour runs in every Siege match (DEC-087)", which reads as if the whole behaviour were new.
