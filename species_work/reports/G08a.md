## New DEC requests

1. **A mode listed twice in a map's mode list** (R-MAP-013). Default: the map is listed twice under that mode. Option B: the schema rejects a repeated mode.
2. **The Essence-orb rain map effect** (R-MAP-092). The flag is in the enumeration, no reference map sets it, and reference/12 specifies no spawner for it. Default: no effect. Options: drop the flag from the schema; or specify a spawner.
3. **Map routes** (R-MAP-120, R-MAP-121). A map may hold routes, but in a match a route id indexes the match's own route table, so map routes are never followed; no reference map has one. Options: drop the routes block; or let starting forces follow map routes.
4. **Structures and starting forces at a closed slot's start position** (edge case 3). DEC-079 lets the host close slots, but every slot below the player count still receives a position, so that position's structures belong to the unused team and its starting forces belong to no playing team. Options: keep; make them no team; or remove them.
5. **An unlimited defender population cap** (table 2.6-A). DEC-120 gives every per-map limit an unlimited form, but the Siege attacker share (map cap − defenders × defender cap) is then undefined. Default written: the defender cap takes absent, 0 or a number. Decide whether unlimited is allowed and what it means.
6. **Non-square maps** (edge case 10). The camera bounds and the Supply crate cap read the world size x only. Every reference map is square. Options: the schema requires square maps; or the rules use z for z.
7. **Reinforcement power option values** (R-MAP-072). I restricted the value to Power kinds whose delivery in reference/04 table 2.2-A is a Power, rejecting other research items (for example the Worker or laser items). The reference accepts any research name. Please confirm.
8. **Population cap 0** (R-MAP-062). Under DEC-120, 0 means none, which locks every Spawn Node and Transit Gate from the first check. Please confirm that this is intended, or let the schema reject 0.
9. **A Trooper starting-forces record that is not in a group** (R-MAP-131). Kept as the reference rule (creates nothing). Option: the content build rejects it.

## Dropped as legacy (one line per group)

- **File-format mechanics:** the text and compressed map formats, keyword case rules, two parsers with different token rules, the header-first rule as a parser stop and the missing-argument crashes. They are replaced by one typed schema and build-time validation (DEC-015, DEC-045, DEC-801, DEC-802).
- **Mission-file content:** the running-power save records, the created-at-difficulty and statistics blocks, the campaign objective conditions, and the secondary-objective derivation (its world-map look-up always fails).
- **Maps outside the reference set:** the development, test, benchmark, sandbox and stress maps, the duel arenas and the unshipped Relic Run map (DEC-334, DEC-058, DEC-063). Their counts are kept only inside the "57 files" census figures, which are labelled as such.
- **Campaign and debug kinds:** the 39 blocked structure kinds and the 16 blocked actor kinds, replaced by the build-time rejection rules R-MAP-101 and R-MAP-131. Also the campaign-only structure kinds found in the sandboxes, and five campaign or debug research items with the campaign research progression.
- **Inert scaling:** the difficulty scaling of team-1 records, which is inert at difficulty 0 (DEC-010).
- **Presentation plumbing:** language-key hashing, thumbnail file naming and texture fallbacks, the demo caption and demo availability, the menu's discard log line and the debug assertions.
- **Writer defects:** the writer that drops zeros and power kind 0, writes only the first mode and positions 0 to 3, and duplicates one option by a fall-through. They are replaced by the lossless-writer rule R-MAP-075 (DEC-800).
- **Names and IP:** map file names, display names, the old mode keyword of Spawn Control, theme words of the colour ramps, and scenery mesh file names. They are restated as anonymous counts, the manifest slot pattern and asset ids.
- **Map permission:** the permitted-map list checks at match entry (the demo and whitelist path).
