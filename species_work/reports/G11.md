## New DEC requests and readings for review

1. **Tutorial mode versus the first playable (coordinator note).** The brief says "the tutorial uses Spawn Control as the first playable (O20)". The reference tutorials are Zone Control matches (ORIG input; DEC-051; R-MODE-083; R-MAP-158; R-VIS-174; R-BOT-150; GameAssets §19). I kept Zone Control, because changing the mode would rewrite the reference and contradict five documents. O20 fixes the first-playable mode; the tutorial assets and maps are priority `launch`. Proposed Open DEC "Tutorial for the first playable": A, no tutorial in the first playable, with the two reference tutorials at launch (default); B, re-author the first tutorial on a 2-player Spawn Control map (the gather, capture, Leader, crate and airstrike lessons carry over; the two Control Zone lessons and the scores tab need replacing). Decide by: design phase (B9). The brief's example string id `tut.spawn_control.capture_first` would fit option B; see "Names" for the prefix.
2. **Objective cards (DEC-050) and 16 pictures.** DEC-050 says the library records the data each objective tab would show. But ORIG 09 §8.3 (lines 1555–1584) is routed DROP-LEGACY (DL-CUT), and no package records it. The 16 manifest rows `help.hint.start_here` … `help.hint.flag_chain_02` are the cards' pictures, with priority `launch` and consumer reference/11, but no rule draws them (R-TUT-013). Request: the coordinator re-routes 09 §8.3 as KEEP-HOOKS (to G09b's hooks file or here), and X-AST moves the 16 rows to `post-launch` or marks them as hook art.
3. **Where the director runs.** DEC-103 does not say. I specified the director as evaluated once per tick of match time on the tutorial player's participant, issuing every world change as a sequenced tutorial event (R-TUT-061, R-TUT-062). Two tab rows read presentation state (the Power-received pop-up, R-CTRL-239), which a purely simulation-side director could not read. Please confirm under DEC-103.
4. **Readings that reviewers should confirm:**
   - hints H4 to H7 are drawn at alpha 1 (only H3 fades; the input gives a fade for H3 alone);
   - the right-edge clamp of a tab mirrors the left-edge test;
   - the step timer starts unset, so that the first request at tick 0 is not refused by the 5-tick gap (the reference timer was a large real-clock value);
   - the director first runs after post-grace tick 0, because the world is held during the grace period (R-SIM-550). The reference evaluated it during the grace period too, with no visible effect.
5. **Launch Race help page 4.** The reference page names a fuel level of 70 for defending the vessel; the rule is 33 (R-BLDG-325). The new text uses the rule's value through `{attack_fuel}`. No DEC is needed unless the owner wants the page to differ from the rule.
