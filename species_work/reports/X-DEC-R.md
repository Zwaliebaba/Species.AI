## Structural change: the index of `verdicts_and_fixes.md`

The file was 117,866 bytes before G2. The mandatory fixes and the extra facts add about 18 KB, and a file may not exceed 120 KB (common rule 9). `g2_merge.py` registers exactly one file for DEC-001 to DEC-199, so the file cannot be split without a change to that script. I therefore replaced the file's per-entry index table (16 KB, 117 rows that repeat the generated `decisions/README.md`) with a **section index**: one row per section with its id range and entry count, headed by a link to the generated register index, which lists every entry of the file with title, status and link. The new entries are in that table (row "9 Further integrity rules: DEC-118, DEC-119"). Two long reference lists were placed with their co-owning entry instead of the verdicts file (DEC-007 → DEC-222 item 2; DEC-013 → DEC-222 item 7), and two lists with their ADR (DEC-012 mesh checks → ADR-0059; the audio generator instance → ADR-0022); each verdicts entry cites where its list is. Result: 119,005 bytes, under 120 KB in either reading (120,000 or 122,880 bytes).
