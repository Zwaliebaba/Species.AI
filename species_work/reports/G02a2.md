## New DEC requests and corrections

1. **DEC-085 contradicts the input (high).** My input specifies that in a match the Builder delivers its orbs to the nearest friendly Spawn Node (plain distance), at node position + front × 50 wu, one orb per tick, each becoming a Worker of the node's owner; only the campaign building it also targets is absent from match maps. DEC-085's "Specified behaviour" ("the orbs a Builder collects reach no destination") rests on that campaign building alone. I wrote the input's rule (builder.md R-UNIT-447, R-UNIT-454, R-UNIT-457) and cite DEC-085 with that default. DEC-085's specified behaviour and options need rewriting (for example: A — the reference rule, delivery to friendly Spawn Nodes, uncapped; B — remove the Builder's collection). The same error is in reference/05 R-ECON-082 and the overview's glossary row for the Builder (cross-document requests below).
2. **DEC-080 status mismatch.** `decisions/README.md` lists DEC-080 as Resolved; its register entry and my package list it as Open. I treated it as Open (specified behaviour = any-team collection, no cap on delivery).
3. **Trooper reload under floating-point stats (new, Open).** The Trooper's stat-table rate (0.5 s) truncates to a per-actor reload of 0 in the reference, so its own reload never blocks; the squad accumulator alone sets the fire rate. With DEC-090's floating-point stats the reload would become 0.5 s and change the fire pattern. Default stated: an explicit reload of 0 ticks (`ref.unit.trooper.reload_ticks`, strike_team.md R-UNIT-341). Options: A — keep 0; B — apply the 0.5 s reload per Trooper.
4. **Transport braking below zero (new, Open).** Inside 10 wu the speed falls by 0.5 wu/s per tick and the input states no floor (transport.md R-UNIT-379). Default: as stated. Recommendation: floor at 0.
5. **Essence orb broken marker (new, Dropped candidate).** The marker is defined (essence_orbs.md R-UNIT-308, as G05 asked) and is never set in a match; the break operation that sets it, its shell render and its break particles have no caller and are not specified.
6. **Collector suck speed near the collector point (clarification).** The input gives 20 wu/s "when nearly level"; I tied "nearly level" to the 5 wu height test of the collection rule (collector.md R-UNIT-431). Please confirm or record as Open.
7. **Collector status text (new, Open, minor).** The Collector shows its idle text while Harvesting and while delivering (collector.md R-UNIT-445), a reference quirk kept under DEC-006. Recommendation: give both states their own text.
8. **DEC-453 is missing the Builder.** Builder deliveries use the same uncapped Spawn Node door spawn as Collector deliveries (builder.md R-UNIT-457); DEC-453's list of uncapped sources should name them.
9. **Flag Chain bot turret search radius (clarification).** The input reads "enemy turrets within zone size × 1.2 (default 200)"; I wrote 1.2 × the Flag post's size, with 200 wu for a default Flag post (transport.md R-UNIT-406, two keys). G01/G03a should confirm the default Flag post size.
10. **Strike team direct-control vectors (clarification).** The input says the lead Trooper is moved "by stick deltas" and the squad fires "at (dx, 0, dy)"; I wrote "waypoint = lead position + movement vector" and "attack along the aiming vector" (strike_team.md R-UNIT-358). G06/C-INP should confirm the scaling of both vectors.
