## ADR conflicts

1. **ADR-0024 against DEC-570.** ADR-0024's baseline graph has four player buses (music, effects, ambience, UI). DEC-570, R-META-434 and R-AUD-221 have six (UI, announcer and stings, voice, world, ambience, music). The graph is data-defined, so six buses fit, but the ADR text and its "each setting changes one bus gain" test should say six.
2. **ADR-0027 against DEC-566.** ADR-0027 adds a per-event maximum distance with a global default. DEC-566's default, which is the reference, has none. R-AUD-202 leaves every event at the engine's global default; C-AEN should set that default beyond the audible range of the event set, or DEC-566 should record the maximum distance.
3. **ADR-0023 ownership.** ADR-0023 makes the engine the owner of every ranking factor. I defined the reference copy decay `ref.aud.rank.copy_decay` (0.75) because the rule is in my range. C-AEN should cite it as its starting value, or the coordinator moves the key.
