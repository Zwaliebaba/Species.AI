## Interpretation notes for the coordinator

1. **Positional binding** (rows 7, 9, 10) is a technology decision that ADR-0061 states outright ("bound by field name, never by row or block order"; typed references by stable id), so no DEC was added. DEC-019 already covers the actor stat table.
2. **DEC-800** is Resolved because ORIG 40 R10 requires a lossless round trip in any new editor and ORIG 29 §12 item 9 recommends a typed, atomic settings store. It also covers the settings writer's defects (lost keys, values used as format directives), which are integrity defects. The settings **file format** stays with DEC-250 (DD-PERSIST); DEC-800 sets only writer and typing rules that hold for any format. DEC-045 (Open, map editor) lists a lossless round trip under option A; DEC-800 makes it a rule for every writer, whichever option DEC-045 takes.
3. **DEC-801** fills a gap in ADR-0059: its validator list names unknown fields and case-variant keys but not duplicate keys, and common JSON parsers accept duplicates silently.
4. **DEC-802** is Open because the routing note asks for the reference default; ORIG gives no fix for maps hidden through an empty mode list. All the other discrepancy rows have a fix by construction (ADR-0059, DEC-801) and are listed in the entry's specified behaviour.
5. **DEC-803** is Open with the default the routing note gives ("kept as an engine capability with no content"). DEC-024 says the unreachable spherical-world and scripted camera modes are not specified; DEC-803 covers only the map-authored move and cut node lists, which DEC-051's preferred option needs.
6. **DEC-804** is Resolved per the routing note ("not replicated in the soak test"). DEC-041 replaces the test bed but does not state the correctness rules that its replacement must keep.

## Extra facts (for the rewrite agents; no new decision)

1. **C-DAT, G08a (map format).** A map holds these sections: match options (first, so a front-end scanner can stop reading early), terrain, terrain tiles, flatten areas, lights, structures, camera views, camera animations, instant units, routes (no reference map uses them) and objectives. Only the first non-empty lights section is used. Every structure that a map defines is a map structure, including a second structures section after the camera animations; the separately loaded, changeable structure set exists only for campaign saves (DEC-052). No reference map holds the author or description field, and the maximum-height field reaches only presentation and the editor (DEC-241 item 12).
2. **C-DAT, G01, G09a (mode option table).** Each mode lists its match options with a minimum, a maximum, a default and a widget kind, where −1 means a checkbox, 0 a drop-down and a positive value the slider step. ADR-0061 forbids sentinels, so Species needs a widget-kind enumeration plus a step field. The table has 7 mode blocks (one of them for the dropped Vehicle Duel) and 39 option definitions; for example, Spawn Control: score mode 0–1 (default 0, drop-down), time limit 0–60 (10, step 1), Catch-up bonus 0–90 (90, step 10), crate drop rate 0–300 (40, step 10), starting powers 0–3 (0, step 1), Comeback Bonus 0–1 (1, checkbox), sudden death 0–1 (1, checkbox), crate drop mode 0–1 (1, drop-down). The full per-mode table is in ORIG 29 §4.3; G01 or G09a should confirm that it reaches reference/01 or reference/09 complete. The reference mode index order is Spawn Control, Zone Control, Relic Run, Siege, Launch Race, Flag Chain, then the dropped Vehicle Duel; maps, the network and the UI all use that index, and a map's mode names must match exactly, case included.
3. **C-AEN, X-DEC-5b (DSP defaults).** A DSP parameter that an effect binding omits is 0.0 in the reference, not the declared default; the declared default column applies only to the sound editor, which seeds new effects with the minimum by mistake. Under ADR-0061, an omitted field takes the schema default, so the schema default of each DSP parameter must be chosen deliberately (0.0 for parity, or the declared value). Because DSP effects are off by default, this has no audible effect until they are enabled.
4. **C-DAT (stats table).** A table with fewer rows than kinds leaves the missing kinds' stats at 0, and a table with more rows ends the program. Under DEC-019 both become build errors (missing record, unknown kind).
5. **C-CAM (camera move orientation).** The reference move-to-target blends orientation through a midpoint rotated by half the sine of the angle (an approximation of half the angle), with quadratic ease-in and ease-out, and forces the up vector to world up every frame. ORIG 30 §8 item 4 recommends spherical interpolation of orientation; DEC-024's "land exactly" rule covers position, and C-CAM should state the orientation law with it. Field-of-view easing runs with a 10 s time constant during scripted moves.
6. **C-PLT, R-META (unread settings).** The reference defaults write a server address, a server port and a network-bypass flag that nothing reads; the live ports are the separate server and client port settings (DEC-250 item 1 lists the saved set). The vertical-sync default differs between the code (on) and the defaults file (off); with DEC-100, one table holds one value.
7. **C-DBG (cheats).** Cheats that change simulation state: kill all enemies; spawn Workers for each of the six team slots; spawn a Transport, Crawlers or Essence orbs (the last draws 20 values from the simulation generator); spawn structure ports; spawn a Supply crate; allow arbitrary placement. Arbitrary placement changes only the local placement check, which every peer re-checks when the placement command executes, so under DEC-041 and DEC-202 it must be a session rule that the server applies, not a client flag. Cheats with no simulation effect: the profiler, sound editor, sound statistics and network statistics windows, and a render-resource reset (trees regenerate from the same per-tree seed).
8. **C-DBG, C-PLT (frame budget).** The reference renders as fast as it can with no sleep in the match loop, clamps the presentation frame delta to 0.25 s, advances audio a second time after rendering when the frame rate is below 15, writes a memory report to the log every 60 s, and pins its main thread to four alternate cores. Its profiler graph marks 50, 100 and 200 ms per frame. Under DEC-225 and ADR-0012 only the 0.25 s presentation clamp has a counterpart to state.
