## New DEC requests

1. **Closed slots (DEC-079 detail).** Defaults written in R-META-090:
   - at least `ref.map.players.min` (2) slots stay open;
   - only a slot that no human holds can be closed;
   - a closed slot is never offered to a joining player;
   - a session is full once every open slot is held;
   - the control also exists in single player.

   To decide: the minimum number of open slots, and whether closing is offered in single player. The reference has no such control.
2. **Chat rename parsing.** The reference finds "/name " or "/rename " anywhere in a line but takes the name from a fixed index (R-META-101), and the rule is kept as a named quirk (DEC-006). Options: A, keep; B, accept the command only at the start of the line.
3. **Studio-mark fade.** When start-up work finishes before the mark has fully faded in, the fade-out starts at full opacity, so the mark jumps (front_end_presentation edge case 2). Options: A, keep; B, fade out from the current alpha.
4. **Play-time format.** The map-select column prints "0:" and the minutes, so 60 minutes reads "0:60" (R-META-038). reference/08 R-MAP-021 calls this "hours and minutes". Options: A, keep; B, true hours and minutes.
5. **Siege side-row test.** The taken test counts the local slot when a row is pressed but not when it is drawn, so a row drawn as free can refuse the press (R-META-080). Options: A, keep; B, one test for both.
