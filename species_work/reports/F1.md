Identifier policy, so that no pattern matches ordinary English:

- compound, qualified, macro and member identifiers are matched as case-sensitive tokens;
- **single capitalised words** (`Tree`, `Building`, `Location`) are matched only in code form (`` `Tree` `` or `Tree::member`), unless they contain a digit (`Vector3`);
- local variables and members are listed only when they carry an IP word;
- 163 generic API names (an API verb plus one or two plain words: `GetPos`, `SetSize`, `IsValid`) are exempt;
- 315 identifiers are already caught by a brand or legacy pattern;
- standard and platform names that Species uses are never listed: `QueryPerformanceCounter`, `CreateThread`, `Direct3D`, `DirectX`, `XInput`, `Win32`, `HLSL`, `std::*`.

### 3.3 Scanner

`python3 -I WORK/scripts/scan_patterns.py [--prose-only] [--counts out.tsv] [--quiet] [--summary] [--exclude GLOB] <patterns.tsv> <path>…`

- It honours the `flags` column and skips fenced code blocks only with `--prose-only`.
- It prints `file:line:class:match` and exits 0 when there is no hit, 1 on hits and 2 on a usage error.
- It recurses into directories, skips `.git` and binary files, and implements the `@strings:` check.
- A literal-substring pre-filter keeps it fast: all 30 ORIG documents (8.7 MB) scan in about 60 s with 1,321 patterns.
