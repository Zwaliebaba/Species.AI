## New DEC requests

1. **Default bindings of demote and scrap (DEC-086).** The input gives no binding for the new demote action. Specified: `action.order.demote` and `action.order.scrap` on the cancel key (C, north face button), demote with a Leader selected, scrap with nothing selected over an own ungrouped actor that is neither a Worker nor a Leader (R-CTRL-044 T4, T5, R-CTRL-045). Please record under DEC-086 or confirm.
2. **Clickable power bar (DEC-083).** Specified: the slot under the pointer takes the focus; `action.power.activate_slot` (primary button up, Enter, or south face button up) selects it; a primary press that starts over the bar is withheld from the world actions; empty slots drawn with `icon.hud.slot_empty` (R-CTRL-226, R-CTRL-230). The activation binding is the reference panel-activation control; the press withholding is my reading of "clickable". Please record under DEC-083.
3. **Secondary-button priority order (DEC-023).** DEC-023 asks for the reference order of the button's five meanings; the input gives each meaning's conditions, not the code order. R-CTRL-050 derives it from the conditions (placing error, toggle under the pointer, order the selected Leader or Transport, crowd order, promote); only rules 2 and 3 overlap, and the input states that the toggle wins. Reviewers should confirm.
4. **Pointer fallback sphere.** On a terrain miss the reference intersects a sphere of radius 40 × a world-size constant that belongs to the dropped campaign globe. Specified as 40 × the world size (R-CTRL-058, `ref.ctrl.pointer.miss_sphere_factor`), as C-SIM-c reads it. Proposed Open DEC, default as specified.
5. **Lock countdown outline pass.** The bar's lock countdown draws its outline pass with a malformed format string (a render defect). Specified: both passes draw the countdown (R-CTRL-232). Proposed Resolved entry.
6. **Smoothing overshoot.** Camera and cursor smoothing x := x(1 − k·dt) + t·k·dt is not clamped where the reference does not clamp it (R-CTRL-454); with the 0.25 s frame-delta cap the free camera reaches k·dt = 1, while the turret crosshair (k = 10) overshoots. Kept as an explicit quirk under DEC-006; proposed Open DEC.
7. **Automatic-camera setting.** It has no options widget, so keyboard players get tracking only by editing settings (R-CTRL-480). Suggest adding it to DEC-050's front-end list.
