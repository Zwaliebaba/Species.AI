## Interpretation notes for the coordinator

1. **H7 (Barrier Emitter lines dilated by one cell in the obstacle grid)** is mapped to DEC-088, not given its own entry. If the three-cell band only selects collision candidates, it changes no result and needs no decision; if it blocks movement wider than the visible line, DEC-088's "Barrier Emitter collision geometry that matches its visible geometry" already corrects it. I could not confirm which, because 21 §6.4 is outside my package. C-SIM-b should state which applies.
2. **H4** (shaped actors re-inserted every tick) has no observable effect once grid results follow the stable order of DEC-016, so it is folded into DEC-650 as a cost note rather than an Open decision.
3. **DEC-650** is Resolved under the brief's integrity rule: a radius change corrupts the grid, which is simulation state.
4. **DEC-651** is Open: ORIG gives no fix for route growth, and the reference default (keep until match end) is harmless in a skirmish match.
5. **DEC-652** is Resolved on ORIG 22's own mitigations for R7 and D22 ("constructors never draw; spawn-time initialisation is an explicit step"; generate the offset table eagerly).
6. **DEC-654** is Resolved on ORIG 22's D19 mitigation; the third-party-code part already appears as DEC-240 constraint 3, which the entry cites.

## Extra facts (for the rewrite agents; no new decision)

1. **DEC-094 / C-SIM-b.** Count queries count whole cells of the square that bounds the range, so they over-count by up to one cell beyond the range. Presence queries test cell capacity, so a cell that has ever held an actor answers "present" for the rest of the match. A cache hit within half the cached range returns the cached list unfiltered, so it includes actors outside the requested range.
2. **DEC-087 / G07, C-SIM-b.** The Barrier-Emitter-blind navigation graph comes from load order: bot target links are computed before the obstacle grid exists. Building the obstacle grid first is the fix.
3. **DEC-088 / C-SIM-b, G03b.** See note 1.
4. **DEC-095, DEC-028 / C-SIM-b.** Two users dereference outside-cell ids without a check: an actor entering a teleport structure, and Strike team direct control. With checked generational handles a stale id is a failed look-up, not a crash.
5. **DEC-007 / C-SIM-c, G03b.** Render writers in the reference: the Barrier Emitter renderer marks its link as absent when the linked id is missing or not a Barrier Emitter, and the update branches on that mark, only for emitters in view (0 dangling links among 703 reference Barrier Emitters; Species validates links at build, DEC-015, and the simulation treats a missing link as absent). The Beam Dish renderer saves and restores its range and receiver around link drawing. A turret's facing is written by render only in the editor. A Supply crate's orientation and bubble timer, a thrown weapon's tumble and flash count, and other presentation fields are stored in simulation objects and read only by render. A Solar Array's orientation from the terrain normal is written by render but equals the value its initialisation sets. The world cursor's crosshair assigns a structure kind instead of comparing it, for the local team's selected structure; it is dormant because only the Beam Dish and turrets can be selected.
6. **DEC-013 / C-SIM-c.** Cosmetic draws on the simulation stream that move to the presentation generator: the ant leg shape (every tick per ant), snowflake and Wisp wobble (four draws per object per tick), meteor fire size (five per tick), Spitter Plant fire size, turret shell casings (four per shot) and overheat smoke, Trooper casings, the Worker abduction spark, and the volcano vent idle draw.
7. **DEC-010 / G08a, C-SIM-a.** Instant-unit copies of the centipedes of team slot 1 exist only at a load difficulty factor above 1, which never occurs in a match, so no map rule specifies them.
8. **DEC-011 / C-SIM-a, G03a.** The Source Node id cache survives between matches but is rewritten at the start of every Source Node update and is first read at least 2 s into a match, so it is harmless; on a map without a Source Node a stale id fails its kind check. A Spawn Node skips its 30 s activation delay when it is its team's only Spawn Node (first or last), which is why the sixth-slot count matters.
9. **DEC-066 / G01, C-SIM-a.** If multi-round Siege is exposed, the round reset must also reset the object id seed, which the reference round reset does not, and run at a tick boundary: in the reference each process advances a variable number of update slices between the round-end flag and the rebuild, consuming simulation draws.
10. **DEC-098 / C-AST, C-RND-b.** Only two reference outcomes of first-requester processing are visible: the colour marker image becomes a white alpha mask when the colour-circle marker pass draws before the recent-Power pass in the first frame, and the no-mip draws of the laser and cloud textures could sample an incomplete texture after a cache flush. Case variants of one name would be separate cache entries; Species ids are lower case (CONVENTIONS §8), so one entry results.
11. **DEC-012, DEC-015 / C-AST, X-AST.** Mesh validator checks: reject duplicate node names (the reference look-up returns the first); reject a hit-test mesh whose position count differs from its vertex count (one of the eight Relic meshes has 1182 positions for 1082 vertices, and the Brood Drifter mesh 43 for 42); accept socket-only meshes with no node. The Relic mesh is chosen by a simulation draw among 8.
12. **DEC-652 / G04.** The Supply crate capture roll against 0.9 is drawn only when no outcome is forced; reference/04 should state the condition.
13. **R-CTRL / G06, C-INP.** A Leader's picking sphere scales with camera distance and the Worker scale preference; it serves local picking only.
14. **R-AUD / G10.** The threat-seen horn plays with a chance of 1 in 200 per threat search, rate-limited by one time stamp shared by all Workers.
15. **VFX / C-VFX, X-DEC-5b.** The Allegiance Scrambler's renderer creates particles, so their count depends on the frame rate; explosion debris advances on frame time.
