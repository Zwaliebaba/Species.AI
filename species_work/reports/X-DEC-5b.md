## Interpretation notes for the coordinator

1. **DEC-101 status conflict (row 1).** The brief's integrity rule makes per-client activation of the seasonal theme a Resolved fix: the theme must be match state, chosen once and identical for every participant, and its snow must not draw from the simulation generator. DEC-101 (X-DEC-1) is Open and still lists the per-client date check as option A. I added no entry, to avoid a duplicate. Suggest that X-DEC-1 either sets DEC-101 to Resolved for activation (option B: the match setup carries the theme, identical for all; snow draws from `FxRng` per DEC-013), leaving open only whether Species ships a seasonal theme, or splits it into two entries.
2. **DEC-102 scope (row 17).** DEC-102 says "all 33 framework defects", which are F1–F33 only. The ten window-core quirks Q1–Q10 are separate items of the same component. Suggest that X-DEC-1 widens the wording to the 10 window-core quirks and the 33 framework defects. Q9, a null access on the maximise path, is a crash defect.
3. **Shared entries with X-DEC-5c (rows 0 and 4).** The X-DEC-5c package marks its positional DSP-blueprint row (29) as "same entry as 26 §9.3" and its panel-parser row as "same entry as 26 §3.7". I wrote no entry for either, because ADR-0061 and DEC-015 already decide them. X-DEC-5c should cite ADR-0061 and DEC-015 too. Otherwise each of us expects the other to write the entry.
4. **Dependence on X-DEC-4b (rows 7, 9, 12, 13).** I cite DEC-567, DEC-569 and DEC-570 from `controls_bots_maps_meta_audio.md` (wave 2b, written in parallel); all three exist as of this report. The X-DEC-4b package also lists "stale effect handles on toggle" (ORIG 10). If DEC-567 takes that item over, DEC-752 can keep only the count-query crash and cite DEC-567 for the rest.
5. **DEC-751** is Resolved under the brief's integrity class "state surviving between matches". DEC-011 covers only simulation state, and DEC-569 does not mention the reset. I recommend a starting time constant of 0.17 s, the reference value with 30 world sounds playing (ORIG 27 §7). That value is my inference for a busy scene, and a playtest may retune it.
6. **DEC-752** is Resolved: the first half is a crash defect, and the second half is an audible defect that ORIG 27 §12.1 calls a defect. The effect-chain defects of 27 §12.6 are not repeated in DEC-752, because ADR-0024 removes them by construction.
7. **DEC-750** is Open. ORIG lists the four panel quirks as defects but recommends no fix: the lead-in and the hidden-before-first-key rule are used deliberately. The default is the reference behaviour, and the recommendation is option B.

## Extra facts (for the rewrite agents; no new decision)

1. **ADR-0023, ADR-0026 / C-AEN (start latency, comparison point).** The reference starts at most one voice per 50 ms audio tick, so at most 20 starts per second system-wide. The tick runs from the real frame delta, capped at 0.25 s; there is no catch-up loop. At 20 frames per second or fewer, one tick runs per frame and the backlog grows. Below 15 frames per second, two updates run per frame and each adds the frame delta again, so the time is counted twice. While paused, the last frame delta keeps being added. A trigger first becomes eligible to start 0–50 ms after it is raised. A one-shot that cannot start gets the start attempts of 3 ticks and is discarded on the 4th, 0.15–0.20 s after its trigger. DEC-570 records the consequence that a burst of 30 explosions takes 1.5 s to start.
2. **DEC-013, ADR-0022, ADR-0026 / C-AEN.** The audio engine owns its own presentation-generator instance and shares none with VFX, terrain or tree generation. Its update runs on its own thread or task (ADR-0026), and DEC-242 recommends one presentation generator per thread. Audio draws are used for the sample-group choice, the random-emitter choice and ranged-random parameters.
3. **ADR-0035 / C-VFX.** The two-bone solver changes the reference look. In the reference, the shin keeps its length and is turned outward by θ = −acos(min(1, 0.4·L ÷ thigh length)), and the thigh is then drawn from knee to hip at whatever length results, so it stretches and compresses. The ratio can exceed 1 and is clamped to 1. In Species, both segments keep their lengths.
4. **ADR-0033 / C-VFX, C-UI-a.** The reference lays out an explainer-animation panel once, when it is created (26 §3.7 #5). Under ADR-0033 the panel is laid out again on a resize, DPI change or language change.
5. **X-DEC-3 / 27-U14.** The ORIG body recommends recording the emitter id at trigger time, so a keep-alive poll made before the next audio update, or for a 2-D or stationary sound, finds the instance. X-DEC-3 can therefore resolve 27-U14 instead of only asking for confirmation. Related fact: in the reference, a stop request with no emitter matches every instance whose emitter was never set, which means all 2-D and stationary sounds.
6. **DEC-102 / C-UI-a (Q8).** The reference has tooltip support in the framework, but nothing registers a tooltip, so no tooltip ever appears. Specify no tooltips. A tooltip feature is front-end design for the design phase.
7. **DEC-102 / G09a, C-UI-b (F17, F21).** In the reference, the host button stays clickable when hosting is not permitted, because menu buttons ignore their disabled flag. When the session list shrinks, its rows are removed at the wrong index, so the Back entry can be removed. Under DEC-102 a disabled widget never acts, and list rows are removed by identity. The hosting permission itself is lobby authority (DEC-243), and the session browser is DEC-245.
8. **DEC-099 / C-UI-a.** In the reference, a missing key shows the key text itself, and a missing table or a null key shows a fixed error text. The miss result lives in one shared buffer that the next miss overwrites (F28, DEC-102). The language chosen at start-up falls back in this order: the language preference, the operating-system locale's language, the base language, then the first language file present. The previous string table stays alive for 5 main-loop iterations after a language change.
